# Release Notes v1.0.3

## 🚀 Nuevas Funcionalidades

### Panel de Administración (Gestión de Usuarios)

- **Gestión Completa**: Nueva sección para administradores que permite listar, crear, editar y eliminar usuarios.
- **Cambio de Contraseña**: Funcionalidad para que los administradores puedan restablecer contraseñas de usuarios.
- **Permisos**: Acceso restringido exclusivamente a usuarios con rol de administrador.

### Hojas de Ruta

- **Notas Internas**: Capability to view and add internal notes within route sheets.
- **Histórico**: Mejora en la carga y visualización de hojas de ruta antiguas.

## 🛠 Mejoras y Correcciones

- **Checklist**: Corrección en el orden de los elementos del checklist para evitar que se muevan al marcarlos.
- **Estabilidad**: Solución de errores de compilación y mejoras generales de rendimiento.
- **Base de Datos**: Script para gestión segura de cambios de contraseña aplicado.
